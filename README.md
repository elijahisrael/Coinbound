# Coinbound

Coinbound is a 2D Unity platformer where the player moves through side-scrolling levels, collects coins, completes goals, and reaches the final win scene.

## Gameplay

The player controls a 2D character through platforming levels. Each level includes collectible coins and goal triggers. The player must complete the required objectives before progressing to the next scene. The final scene displays a win condition when the player completes the game.

## Features

- 2D side-scrolling player movement
- Jumping and platforming
- Coin collection
- Score display
- Goal trigger system
- Multiple scene transitions
- Final win scene
- Smooth camera follow
- Unity 2D physics
- C# gameplay scripts

## Controls

| Action | Input |
|---|---|
| Move Left | Left Arrow |
| Move Right | Right Arrow |
| Jump | Up Arrow |

## How to Open the Project

1. Install Unity Hub.
2. Clone this repository.
3. Open Unity Hub.
4. Choose **Add project from disk**.
5. Select the root folder of this repository.
6. Open a scene from `Assets/Scenes`.
7. Press Play.

## Main Scenes

- `Assets/Scenes/First_Scene.unity`
- `Assets/Scenes/Second_Scene.unity`
- `Assets/Scenes/Final_Scene.unity`

## Repository Notes

This repository contains the Unity source project files. Unity-generated folders such as `Library/`, `Temp/`, `Obj/`, `Build/`, `Builds/`, `Logs/`, and `UserSettings/` are intentionally ignored because Unity recreates them locally.
